# 深海湾配色尝试

基于用户已确认的连续海湾布局。入口为 `landing-blue.html`，原 `landing-experiment-07.html` 保留对比。

## 配色

- 海面：明亮天蓝过渡到饱和的近岸蓝，以空间深浅区分近岸与远海，沙滩使用较实的暖沙色收住画面。
- 主文字与操作：深海蓝 `#29485F`、`#3B709C`。
- 中央玻璃瓶：使用画面中唯一的大面积琥珀暖色，并增加双侧高光、瓶身色差、内部暖色信纸和更清楚的软投影。
- 瓶子柜与经历小屋：取消依靠低透明度退后的做法，使用完整实体色、较深蓝色屋顶和明确落地阴影；通过较小尺度、冷色归属和更少材质细节保持次级地位。
- 信纸与弹窗：蓝白纸面、淡蓝横线，来信封签改为灰蓝。
- 海岸与木棚：保留少量浅沙色，屋顶偏灰蓝；经历开放时窗光仍为淡暖黄。

## 范围与验证

## 晴朗海湾调整

针对「空洞、灰暗」的反馈，背景增加清晰的空间与生活层次：左上方暖日光、远处海平线和岛影、三组淡云、两组飞鸟、水面高光以及近岸的浅水纹理。动画速度保持缓慢，并遵守减少动态效果偏好。

瓶子使用琥珀色与暖金高光形成全页唯一的暖色核心。柜棚和小屋恢复实体感，背景海水也加深一层；主体地位由尺度、互补色和玻璃细节建立，而不是靠周围对象变淡。烟迹及窗光表达有人生活；来瓶状态会在远海显示微弱的琥珀亮点。这些环境细节均不承担新的功能入口。

本次仅试配色，布局和交互控制脚本与已确认版本保持一致。两版共用现有本地存储键，记录不会因为换色被清空；并排打开时不提供实时跨窗口同步。

已检查脚本语法、DOM 引用，并针对蓝色文件通过查看/接住区分、草稿切换、回信续写、归档、连续新瓶、放行与重载状态测试。尚未在浏览器中实际验证 WebGL 渲染和配色观感。蓝色尚未确认为最终配色。
