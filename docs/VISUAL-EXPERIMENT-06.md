# 交互尝试 06：展开、折回、出发

2026-09-07。独立原型 `landing-experiment-06.html`。仅为可修改尝试，不覆盖长期约束。

## 随机来源与推导

首先通过 Shell 从 `/dev/urandom` 读取 768 字节，转换成 1536 位十六进制字母数字串。完整串不进入页面。

- 成对的 bb、dd：对应可逆的两面状态，瓶中与展开；编辑后仍能打开重写。
- 连续的 eeee：对应逐段展开的一张信纸，不切换到与瓶子无关的页面。
- 长数字段中的字符断点：对应四个明确节拍，开瓶、写信、装好、出发。
- 闭合字符轮廓与长串线性结构：对应封签与向上抛出的方向。拖拽是可选增强，点击与键盘按钮提供相同路径。

色彩为对材质和状态的主观转译：浅海灰呈现静止背景，米白用于展开信纸，灰绿用于可操作项，黄铜色封签表示内容已装好。没有「字符客观代表色彩」的主张。

## 交互规则

1. 初始只有瓶子作为视觉主体。点瓶子或「打开瓶塞」按钮，瓶塞抬起，信纸展开。
2. 在信纸选择「我正在经历」或「我走过的」，两种正文草稿在当前页面内分开保留。
3. 求助填写目标经历；分享需本人确认，可选是否愿意接收邀请及一句回望。
4. 预览后点击「卷好信纸，放回瓶中」。纸张收回，瓶口合上，瓶子出现封签。此时尚未执行最终动作。
5. 求助可向上拖动超过 65px 或点击按钮播放抛出；分享使用「把这段经历留下」。两者均可再次打开修改。
6. 完成演示后提示未发送、未保存。点击「让瓶子回来」可继续编辑。

## 视觉与适配

- 瓶子居中，页面只在底部提供很轻的四阶段提示；不增加独立输入卡和宣传区。
- 信纸标题采用系统宋体衬线，输入和按钮用系统无衬线，正文 14px、行高 32px。
- 桌面与手机采用相同动作逻辑。手机画布独占触摸旋转与上抛，画布外仍可滚动。键盘使用按钮完成所有步骤，不强制手势。
- 原生弹窗支持 Escape、聚焦和收起。减少动态效果偏好下跳过卷纸动画，关闭位移动画。

## 实现边界

使用原生 WebGL 立体瓶与本地状态，不依赖网络库。无 WebGL 时提供静态替代，所有表单动作仍可由按钮完成。没有 AI、匹配、消息或持久保存。
