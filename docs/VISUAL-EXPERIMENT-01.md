# 视觉尝试 01：错位相遇

日期：2026-09-07。仅为可修改的视觉实验，不覆盖长期产品约束。

## 灵感来源与推导

以 Shell 从 /dev/urandom 采样的 768 位随机字母数字串作为唯一视觉灵感，不采用外部参考图或模板；原串不进入页面。

- O、0、8 的闭合轮廓 → 大圆角输入窗口、两枚有孔的标签、相互接近的圆形轨迹。
- X、V、W 的斜向笔画 → 两条交叉路径、轻微旋转的叠卡、斜向箭头；正文保持水平以保证阅读。
- 大小写的高低变化 → 大字号简短标题与克制的小标签对比，减少中间层级。
- 00、998、666 的连续重复 → 三个节拍的流程，同时以双卡构图强调两个不同时间阶段的人相遇。
- 字母长段与数字短段交替 → 首屏约 6:4 非对称布局，长叙述留白，短动作高对比。

色彩是对字符节奏的主观转译，不声称字符存在客观色值：密集段对应深紫 #30233F，疏松段对应浅紫 #E5DBF4，突出的数字节拍对应酸黄 #E5FA72，阅读区以暖白 #FAF9F6 过渡。

## 字体与布局规范

中文使用系统无衬线 PingFang SC / Microsoft YaHei，英文辅助使用 Arial；无需在线字体。桌面主标题 68–88px，手机 40–48px；正文 15–17px，行高 1.7；按钮 14–16px。仅辅助装饰采用衬线大字。

桌面宽屏左右双列，手机变为输入优先的单列，减少装饰并使用底部快捷入口。首屏输入处境，例子可一键填入；用「你想听谁说说」代替内部条件术语。页面不展示随机串、匹配分数、身份光环或伪造用户量。

`landing-experiment.html` 为独立网页与手机自适应落地页；轻量本地交互仅用于体验输入、确认和经历填写。明确无真实 AI、无真人匹配、无消息发送。保留原 `index.html` 以供对比。
