# 交互尝试 07：一片属于你的海

独立原型：`landing-experiment-07.html`。中央瓶子为 WebGL 三维网格；侧边柜子与岛为 CSS 立体结构，可点击进入、在查看窗口横向拖动旋转。侧物体体量和色彩均弱于中央瓶子。

## 三个入口

- 中央瓶子：填写当前处境和目标经历，预览后抛出。保存独立记录，再写一个时得到空白表单，旧记录不覆盖。
- 瓶子柜：切换「我抛出的 / 我捡到的」，点击查看内容。捡到的预置记录明确为示例，可留演示回信或这次不聊；不是公共求助广场，不展示候选人。
- 小岛：添加、编辑已走过经历，本人确认及接收开关独立保存；不随瓶子变化。

视觉层级调整：瓶子柜放大为中央瓶子后方的低对比背景陈列架，记录增加时架上可见的小瓶数量增加；小岛下沉到海面下方作为淡化底景。两者默认降低饱和度和透明度，获得焦点或悬停时才稍微显现，避免与中央漂流瓶竞争。

## 场景与行为的联系

- 最新尝试移除木栈道、连接线和码头灯。画面下方是一段连续海湾岸线，柜子落在左侧木棚内，经历入口是右侧小屋，中央瓶子漂在近岸水面。通过沙滩、浅水、泡沫线、共同的柔和光照和落地阴影建立空间关系。
- 新请求确认后，瓶子向远海缩小漂走；柜内随后增加记录，中央自动补上全新空瓶。来瓶从远海漂近。瓶子不再飞进柜子。保存仍是本地演示，画面不声称完成真人发送。
- 岛上有主动开放的经历时，屋内窗户呈暖色；关闭所有接收后回到安静状态。窗光表示接收意愿，不是等级或成就。
- 柜子的「我捡到的」说明与岛上开放经历的关系，并可直接进入小岛编辑。示例瓶子明确标识，不把它伪称为经历匹配结果。
- 收好记录后的轻提示提供查看柜子的入口，不以全屏结束页阻挡中央的新瓶子。

## 中央瓶子的捡起流程

- 中央在空瓶与示例来瓶之间切换。来瓶从远处漂近，带纸卷、棕色封签和「捡起来看看」动作。
- 捡起只查看，不自动承诺回应。接收者选择「我演过，接住这一集」后，瓶子才进入柜子的来信记录。
- 「这次不聊」「这段我没经历过」均放行，无惩罚。关闭未接住的信纸表示稍后再看。
- 接住后在中央信纸回信；关闭会保留本地回信草稿。柜子中尚未写完的瓶子会返回中央继续编辑，已完成的回信在柜中查看。
- 「我也想写一瓶」切换到自己的瓶子，正文和目标经历保留在当前页面；这不承诺刷新后仍保留未抛出的草稿。
- 来瓶队列逐个查看。回复或放行的示例不会自动重新出现；没有待处理来瓶时，可主动点击「试捡一只示例瓶子」再次体验。
- 所有示例均明确非真实匹配，不根据未确认的经历推断「你演过」。已有本地记录按已回复、已放行等状态迁移。

验证：对实际页面控制脚本进行无浏览器的 DOM 替身状态测试，覆盖查看与接住区分、草稿切换、回信续写、归档、新建多个瓶子、两类放行及重载状态。此测试不验证 WebGL、浏览器布局、动画或触屏效果。

## 存储和边界

使用 `localStorage`，键名 `episode-world-v07`。刷新后在同一浏览器、同一来源保留，不能跨设备同步，清除站点数据会丢失。不存储密钥，无远程请求；用户输入通过 textContent 展示。若存储不可用，告知仅当前页面保留。

支持连续创建不代表并行真人匹配。原 PRD 的单主动匹配限制与多瓶的关系仍待明确；本版仅保存独立记录。无真实账号、AI、真人邀请或消息发送。

已检查 HTML 嵌套、唯一 ID、脚本 DOM 引用与 JavaScript 语法。浏览器渲染、触屏拖动、本地存储跨刷新及完整流程尚未自动化验证。
